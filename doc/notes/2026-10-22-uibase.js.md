Le fichier est maintenant cohérent avec le CSS :

un seul état visuel : active
pas de hidden
pas de logique de remove("active", ...)
les panels visibles/invisibles sont pilotés uniquement par classList.toggle(this.pgc.classPanelActive, active)
À ce stade, le bon contrat est :

UiBase gère uniquement l’état du document
ui.css contrôle la visibilité
le HTML/JS ne manipulent pas hidden pour les articles
Tu peux maintenant considérer que le mécanisme est propre et stable.

Le point final à vérifier, c’est l’état initial :

au chargement, il faut qu’un article soit actif
sinon tout reste masqué
Donc ce que je te recommande pour sécuriser le démarrage :

```js
readPage() {
  ...
  if (this.articles.length > 0) {
    const firstContentIndex = this.pgc.offsetPanel;
    if (this.articles[firstContentIndex]) {
      this.switchPanel(firstContentIndex);
    }
  }
}
```
ou, si tu veux garder la logique plus explicite :

```js
this.currentArticle = this.pgc.offsetPanel;
this.switchPanel(this.currentArticle);
```
C’est une bonne garde-fou pour éviter les panneaux “invisibles au boot”.
